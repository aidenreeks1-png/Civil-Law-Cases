# Civil Law Case Files — GitHub Pages

A small static website for Year 9 Commerce containing two interactive civil-law simulations.

## Files

- `index.html` — landing page students open first
- `patel-v-elevate.html` — core negligence simulation
- `wilson-v-bauer.html` — extension defamation simulation
- `.nojekyll` — tells GitHub Pages to serve the files as a simple static site

## Publish with GitHub Pages

1. Create a new GitHub repository, e.g. `civil-law-case-files`.
2. Upload **all four files from this folder to the root of the repository**.
3. Commit the files.
4. In GitHub, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`, then click **Save**.
7. GitHub will display the public Pages URL after deployment.
8. Put that public URL into Google Classroom as a **Link**.

Students do not need a GitHub or ChatGPT login to use a public GitHub Pages site.

## Classroom suggestion

Use `Patel v Elevate` as the core activity in groups of four. Use `Wilson v Bauer Media` as an extension for early finishers or higher-ability students.
